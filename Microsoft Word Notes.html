📚 MS Word Introduction

What is MS Word?

MS Word is a word processing software developed by Microsoft. It is used to create, edit, format, save and print documents.

Uses of MS Word

  • Letters
  • Reports
  • CV and Resume
  • Notices
  • Certificates
  • Assignments
  • Tables
  • Mail Merge
  • Pictures and Shapes
  • Professional Documents

Important Parts of MS Word

PartFunction
Title BarDisplays document name.
Quick Access ToolbarProvides quick access to common commands.
RibbonContains tabs, groups and commands.
Document AreaArea where we type and edit.
RulerUsed for margins, indents and tabs.
Status BarDisplays page and word information.
Scroll BarMoves through the document.

📊 SmartArt & Charts

🧩 SmartArt

SmartArt is used to present information visually through diagrams.

SmartArt भनेको जानकारीलाई विभिन्न Diagram तथा Graphic को माध्यमबाट दृश्यात्मक रूपमा प्रस्तुत गर्ने सुविधा हो।

1. List SmartArt

Point 1
Point 2
Point 3

Use: Displays related information as a list.
Path: Insert → SmartArt → List

प्रयोग: सम्बन्धित जानकारीलाई List को रूपमा देखाउन प्रयोग गरिन्छ।
Path: Insert → SmartArt → List

2. Process SmartArt

Planning → Designing → Development → Testing

Used to show step-by-step processes.

कुनै कामका क्रमिक चरणहरू देखाउन प्रयोग गरिन्छ।

3. Cycle SmartArt

दोहोरिरहने Process देखाउन प्रयोग गरिन्छ।

📈 Chart Types

1. Column Chart

English
Math
Science
Computer

Used to compare values between categories.

विभिन्न Category का Values तुलना गर्न प्रयोग गरिन्छ।

2. Bar Chart

Computer
Math
English
Science

Compares values horizontally.

Values लाई Horizontal रूपमा तुलना गर्छ।

3. Line Chart

Shows trends over time.

समयसँगै भएको Trend देखाउँछ।

4. Pie Chart

Shows percentage or parts of a whole.

कुल Data को Percentage वा भाग देखाउँछ।

5. Doughnut Chart

Similar to Pie Chart with a center hole.

Pie Chart जस्तै हुन्छ तर बीचमा खाली भाग हुन्छ।

6. Area Chart

Shows trend and magnitude.

Trend र Magnitude देखाउन प्रयोग गरिन्छ।

7. Scatter Chart

Shows relationships between numerical variables.

Numerical Variables बीचको सम्बन्ध देखाउँछ।

8. Radar Chart

Compares multiple variables.

धेरै Variables लाई तुलना गर्छ।

Insert SmartArt: Insert → SmartArt → Select Category → Select Design → Enter Text

Insert Chart: Insert → Chart → Select Chart Type → Enter Data
